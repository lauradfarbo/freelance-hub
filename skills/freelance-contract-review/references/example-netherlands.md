# Worked Example: Netherlands (ZZP / eenmanszaak)

Use this when the freelancer is Dutch or the contract is under Dutch law. It also shows the shape of a finished jurisdiction brief for other countries. Statute references and rates below are starting points to verify with current sources before relying on them. Last reviewed October 2026.

## Jurisdiction snapshot

| Topic | What the law gives you by default | What the contract must add |
|---|---|---|
| Classification | Wet DBA enforcement resumed in 2025. A client that treats a freelancer like an employee carries risk, and so can the freelancer. The Zelfstandigenwet (self-employment law) is expected no earlier than 2027, so watch for changes. | Defined deliverables, an end point, other clients permitted, no set hours or methods |
| Late payment | Statutory commercial interest (handelsrente, art. 6:119a BW) applies to late B2B payment. Large companies must pay small suppliers within 30 days. Collection costs can be claimed under the Wet Incassokosten. | Shorter terms and explicit interest and collection costs if you want more than the default |
| Cancellation fee | Enforceable, but a penalty (boete) can be moderated by a court (art. 6:91–6:94 BW). | Word it as compensation (vergoeding) tied to reserved time and work done |
| Scope | An assignment (opdracht, art. 7:400 BW) should define the work. Vague scope favours the client in disputes. | Named deliverables and a change-order clause |
| Tacit acceptance | Silence can count as acceptance, but a written clause makes it clear (art. 6:217–6:219 BW). | Written feedback within 5–7 working days, otherwise accepted |
| Suspension | A right to suspend performance exists for non-payment (opschortingsrecht, art. 6:52 BW). | State that work starts on receipt of the deposit and pauses if an invoice is unpaid |
| Copyright | Stays with the creator unless transferred in writing (Auteurswet). Moral rights (art. 25 Aw) cannot be fully waived. | Portfolio carve-out whenever IP is assigned. Narrow broad moral-rights waivers |
| Liability | Exclusion for intent or gross negligence is not enforceable. | Cap at fees paid, mutual if possible |
| Data | AVG (the Dutch GDPR) applies whenever personal data is processed. | A verwerkersovereenkomst (processor agreement) |
| VAT | Standard rate 21%. Reverse-charge (BTW verlegd) for eligible cross-border B2B services. | Prices stated exclusive of BTW |

Dutch invoices must show the KvK number and BTW number.

## Dutch drafting notes

- Use *vergoeding* (compensation) for cancellation fees, not *boete*.
- Prefer outcome language ("ter uitvoering van de overeengekomen opdracht") over direction language ("in opdracht van en onder leiding van").
- Where a Dutch-language version is needed, write the clause in plain English first, then have it translated or checked by a Dutch lawyer.
- Foreign clients: aim for Dutch law and a Dutch court. If they refuse, ask for a neutral venue or arbitration and escalate to a lawyer for contracts of real value.

## Common Dutch-specific traps

- Language implying employment: "part of the team", set days in the office, exclusivity, open-ended duration.
- Clauses that make the freelancer liable for the client's payroll tax or social contributions if the Belastingdienst reclassifies the relationship. Treat as a pre-signing item.
- Client-supplied tools and workspace as the only option, with no right to substitute.
